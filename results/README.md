# Results

This folder contains experimental results associated with the evaluation reported in the paper.

Currently, results are provided as spreadsheet files generated during the experimental campaign.

## Authoritative archive (Open Data / FAIR)

The authoritative and citable archive of the experimental results — including interoperable CSV files
and detailed column semantics documentation — is available in RUO:

https://hdl.handle.net/10651/81943

Users interested in reuse or replication are encouraged to rely on the RUO dataset rather than
local copies.
