# Data

This folder contains workflow instances and host configuration files used during the
experimental evaluation.

These files are provided here for reference and lightweight experimentation.

## Authoritative archive

The authoritative, citable and complete version of the data and experimental results
is archived in the University of Oviedo Institutional Repository (RUO):

https://hdl.handle.net/10651/81943

## Structure

- `hosts/`: JSON files describing host configurations (number of computing resources).
- `workflows/`: JSON workflow instances derived from WfCommons benchmarks.
